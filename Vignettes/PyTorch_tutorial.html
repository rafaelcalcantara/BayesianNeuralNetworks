Model setup

In this vignette, we will run the tutorial from https://pytorch.org/tutorials/beginner/basics/intro.html and add a hook that extracts the output from any given layer in the neural network.

First, we load the relevant libraries:

import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import DataLoader
from torchvision import datasets
from torchvision.transforms import ToTensor

To download the train and test data for the tutorial, we use the datasets class from torchvision, which is a subclass of the general Datasets class from torch.utils.data. We will work with data from the Fashion-MNIST dataset, which consists of samples of 28x28 grayscale images and labels from a total of 10 classes.

# Download training data from open datasets.
training_data = datasets.FashionMNIST(
    root="data",
    train=True,
    download=True,
    transform=ToTensor(),
)

# Download test data from open datasets.
test_data = datasets.FashionMNIST(
    root="data",
    train=False,
    download=True,
    transform=ToTensor(),
)

Then, we create data loaders for each data set. DataLoader is a class from torch.utils.data which ``wraps an iterable around the Dataset to enable easy access to the samples’’ (from the PyTorch tutorial on data classes; see documentation for more details).

batch_size = 64

# Create data loaders.

test_dataloader = DataLoader(test_data, batch_size=batch_size)

We can now proceed to create a basic NN model. Each model is defined by a class which must be a subclass of torch.nn.Module, a loss function and an optimizer. We also define functions to train and test the model, and a hook that is registered to the model object after training, which extracts the output from a given layer.

Model class

This model consists of 3 linear layers, with a ReLU activation function between each.

# Define model
class NeuralNetwork(nn.Module):
    def __init__(self):
        super(NeuralNetwork,self).__init__()
        self.flatten = nn.Flatten()
        self.l1 = nn.Linear(28*28, 512)
        self.l2 = nn.Linear(512, 512)
        self.l3 = nn.Linear(512, 10)

    def forward(self, x):
        x = self.flatten(x)
        x = self.l1(x)
        x = F.relu(x)
        x = self.l2(x)
        x = F.relu(x)
        x = self.l3(x)
        x = F.log_softmax(x,dim=1)
        return x

model = NeuralNetwork().to(device)
print(model)
NeuralNetwork(

  (l3): Linear(in_features=512, out_features=10, bias=True)
)

Loss function and optimizer

loss_fn = nn.CrossEntropyLoss()

Train and test functions

def train(dataloader, model, loss_fn, optimizer):
    size = len(dataloader.dataset)
    model.train() ## Get into training mode
    for batch, (X, y) in enumerate(dataloader):
        X, y = X.to(device), y.to(device)

        # Compute prediction error
        pred = model(X)
        loss = loss_fn(pred, y)

        # Backpropagation
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()

        if batch % 100 == 0:
            loss, current = loss.item(), (batch + 1) * len(X)
            print(f"loss: {loss:>7f}  [{current:>5d}/{size:>5d}]")
            
def test(dataloader, model, loss_fn):
    size = len(dataloader.dataset)
    num_batches = len(dataloader)
    model.eval() ## Tell it to not train the model again (go into evaluation mode)
    test_loss, correct = 0, 0
    with torch.no_grad(): ## Don't calculate gradients (since it's not training)
        for X, y in dataloader:
            X, y = X.to(device), y.to(device)
            pred = model(X)
            test_loss += loss_fn(pred, y).item()
            correct += (pred.argmax(1) == y).type(torch.float).sum().item()
    test_loss /= num_batches
    correct /= size
    print(f"Test Error: \n Accuracy: {(100*correct):>0.1f}%, Avg loss: {test_loss:>8f} \n")

Hook for layer output

Add hook to extract a given layer 1 2:

activation = {}

def hook(model, input, output):
  activation['l3'] = output.detach()
